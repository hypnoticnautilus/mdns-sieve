Dashboard Help & Guide

Network Traffic Graph

The network traffic graph displays real-time packet activity. It updates dynamically according to the auto-refresh settings and shows the counts of forwarded, dropped, and rewritten mDNS packets over time to help you identify trends or anomalies.

Domain Names Explorer

The "Domain Names Explorer" panel displays mDNS service types/domain queries and responses aggregated by service name. You can expand a domain to inspect the source IPs querying or responding to that service, apply real-time filters by search query, packet interface, or packet action, and observe active interfaces.

Active Hosts Panel Purpose

The "Active Hosts" panel maps out which source IP addresses are transmitting traffic on local network interfaces. It allows network administrators to see active devices, verify interface routing layout, and spot idle states.

Top-Right Icon Controls

The settings gear icon allows adjusting chart buffers and poll schedules locally. The info button exposes current connection profiles and debug diagnostics.
