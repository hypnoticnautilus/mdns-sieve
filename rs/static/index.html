Dashboard Help & Guide

Network Traffic Graph

The network traffic graph displays real-time message activity across all configured interfaces, tracking Total, Forwarded, Partially Forwarded, and Dropped mDNS messages over time.

Message History & Dispositions

The "Message History" view records every received mDNS message along with the disposition of every individual question and resource record inside it:

  • Green Dot (Forwarded): Forwarded to all candidate destination interfaces.
  • Yellow Dot (Partially Forwarded): Forwarded to a subset of destination interfaces, or packet had some records stripped while others were forwarded.
  • Red Dot (Dropped): Blocked on all destination interfaces.

Top-Right Icon Controls

The settings gear icon allows adjusting chart buffers and poll schedules locally. The info button exposes current connection profiles and version diagnostics.
